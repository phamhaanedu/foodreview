# FoodReview - Ứng dụng Đánh giá Ẩm thực (Bản Phát hành)

Đây là thư mục chứa bản build hoàn chỉnh (Production Build) của dự án **FoodReview**. Các tệp tin trong thư mục này đã được tối ưu hóa, nén dung lượng và sẵn sàng để triển khai (deploy) lên các máy chủ web hoặc dịch vụ hosting tĩnh (như Vercel, Firebase Hosting, Netlify, hoặc GitHub Pages).

## 🌟 Giới thiệu nhanh
FoodReview là nền tảng chia sẻ và review địa điểm ăn uống được tích hợp mạnh mẽ với Trí tuệ Nhân tạo (Google Gemini API).

### 🚀 Tính năng nổi bật
*   **Bản đồ & Danh sách quán ăn**: Hiển thị danh sách quán ăn kèm định vị, món ăn đặc trưng, số sao đánh giá.
*   **Tích hợp AI**: 
    *   Nhập nhiều quán ăn hàng loạt bằng AI (Batch Import).
    *   Tự động bóc tách Tên món và Giá tiền từ ảnh Menu (Menu OCR).
*   **Tìm kiếm giọng nói**: Hỗ trợ tìm kiếm rảnh tay qua Web Speech API.
*   **Quản trị & Phân quyền**: Đăng nhập bằng Google (Firebase Auth), kiểm duyệt nội dung, báo cáo đóng cửa.
*   **Hiệu năng cao**: Tải trang nhanh với kỹ thuật Lazy-loading, tự động nén ảnh từ trình duyệt trước khi tải lên Google Drive.
